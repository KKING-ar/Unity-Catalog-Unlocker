CATALOG UNLOCKER — GUIDE

Unlocks Unity Addressables catalogs by disabling their built-in CRC / integrity checks, so you can freely edit or replace asset bundles without the game rejecting them as "corrupted".

1. Choose the format

Pick catalog.bin or catalog.json with the pills above the drop zone — it's also auto-detected from the file extension when you drop a file.

2. Drop your catalog file

The tool scans it and lists every bundle entry it can find, showing each one's current CRC value and size.

3. Review the entries

An entry showing a CRC number still has integrity checking enabled. An entry already showing "DISABLED" has already been unlocked.

4. Disable All CRC Checks

Zeroes every CRC field. For catalog.bin this rewrites the CRC bytes directly in the binary buffer. For catalog.json it renames the "m_Crc" key to "d_Crc", which Unity's Addressables loader ignores — disabling the check the same way.

5. Hash recompute

A new catalog.hash (MD5 of the patched file) is generated automatically, since Unity validates the catalog against this hash before loading it.

6. Download and replace

Download the patched catalog file and the new catalog.hash, then place them in the same folder as the originals (typically your game's StreamingAssets folder), overwriting the old ones.

Notes

Everything runs locally in your browser — no file is ever uploaded anywhere. The Operation Log at the bottom records every step for troubleshooting.

تقوم هذه الأداة بفك قفل كتالوجات Unity Addressables عبر تعطيل فحوصات CRC / سلامة الملفات المدمجة فيها، لتتمكن من تعديل أو استبدال حزم الأصول (bundles) بحرية دون أن ترفضها اللعبة باعتبارها "تالفة".

١. اختيار الصيغة

اختر catalog.bin أو catalog.json من الأزرار أعلى منطقة الإفلات — يتم اكتشافها تلقائياً أيضاً من امتداد الملف عند إفلاته.

٢. إفلات ملف الكتالوج

تفحص الأداة الملف وتسرد كل حزمة (bundle) تجدها، مع قيمة CRC الحالية وحجم كل منها.

٣. مراجعة الإدخالات

الإدخال الذي يظهر فيه رقم CRC لا يزال فحص السلامة مفعّلاً عليه. الإدخال الذي يظهر عليه "DISABLED" تم فك قفله مسبقاً.

٤. تعطيل جميع فحوصات CRC

يصفّر كل حقول CRC. بالنسبة لـ catalog.bin يعيد كتابة بايتات CRC مباشرة داخل الملف الثنائي. بالنسبة لـ catalog.json يعيد تسمية الحقل "m_Crc" إلى "d_Crc"، وهو حقل يتجاهله محمّل Unity Addressables — ما يعطّل الفحص بنفس الطريقة.

٥. إعادة حساب الهاش

يتم توليد catalog.hash جديد تلقائياً (MD5 للملف المعدل)، لأن Unity يتحقق من الكتالوج مقابل هذا الهاش قبل تحميله.

٦. التنزيل والاستبدال

نزّل ملف الكتالوج المعدل وملف catalog.hash الجديد، ثم ضعهما في نفس مجلد الملفات الأصلية (عادةً مجلد StreamingAssets في لعبتك)، مع استبدال الملفات القديمة.

ملاحظات

كل شيء يعمل محلياً داخل متصفحك — لا يتم رفع أي ملف إلى أي مكان. سجل العمليات أسفل الصفحة يسجّل كل خطوة لأغراض استكشاف الأخطاء.
